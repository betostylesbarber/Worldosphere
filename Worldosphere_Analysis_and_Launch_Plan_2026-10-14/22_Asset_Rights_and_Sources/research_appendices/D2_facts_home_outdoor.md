## Read this first: how this ledger was built and how far to trust it

- **Direct page fetching did not work in this session.** WebFetch failed with a DNS error (`ENOTFOUND`) for every host tried, including cdc.gov, cpsc.gov, ready.gov, fema.gov, nps.gov and wikipedia.org. Fetching with the command line was refused by the session's permission policy. So **no source page was opened directly.**
- **All evidence comes from a web-search tool.** That tool returns the page URL and extracts text from the page. Each quote is tagged by how sure we are of the wording:
  - **[Q]** means the search index returned this as a literal string from the page. Treat it as verbatim, but still spot-check before showing it on screen.
  - **[P]** means the search index paraphrased the page, so the exact sentence was not retrieved. The fact is supported, but **do not put this text on screen as a direct quote** until someone opens the page.
- **The search budget ran out partway through.** The session limit of 200 searches is shared by all agents. Every section after ELEVATORS (outdoor, wildlife, nuclear, sound, crowds, the CDC zombie campaign and quicksand) could not be checked. Those rows are marked **UNVERIFIED** and list candidate sources for a follow-up pass. They contain no new numbers.
- Verdicts: **SUPPORTED** means confirmed as stated. **QUALIFIED** means mostly right but needs a caveat or rewording. **FALSE** means contradicted by the sources. **UNVERIFIED** means it could not be confirmed this session.

### Livestock water calculation (derived from the cited ranges)

Assumptions: 12 mature beef cows at about 1,100 lb (OSU table, not lactating); 1 horse at about 1,000 lb; 30 laying hens; 1 dog at about 50 lb; 1 adult human at 1 gal/day.

| Animal | Cool day (~40 °F) | Hot day (~90 °F) | Basis |
|---|---|---|---|
| 12 cattle | 12 × 8.2 = **98.4 gal** | 12 × 13.4 = **160.8 gal** (12 × 20 = 240 gal if lactating) | OSU, NDSU |
| 1 horse | **10 gal** | **12–18 gal** (18 used) | Purdue, UMN, Iowa State |
| 30 hens | 30 × 5/100 = **1.5 gal** (1.9 at K-State's 6.3) | 30 × 10.57/100 = **~3.2 gal** | Penn State, K-State, UKY |
| 1 dog (~50 lb / 22.7 kg) | **~0.24–0.36 gal** (0.9–1.4 L) | **~0.63 gal** (10 cups, TAMU upper guide) | Cornell, TAMU |
| **All animals** | **≈110 gal/day** | **≈183 gal/day** (≈262 if cows lactating) | |
| **73 gal lasts** | **≈0.66 day (≈16 h)** | **≈0.4 day (≈10 h)**; ≈7 h if lactating | |
| Cattle alone | 73 ÷ 98.4 = **≈0.74 day (≈18 h)** | | |
| Without the cattle (horse + hens + dog + farmer) | ≈12.7 gal/day → **≈5.7 days** | ≈22.8 gal/day → **≈3.2 days** | |
| Farmer alone at 1 gal/day | **73 days** | | Ready.gov / CDC / Red Cross |
| "Weeks" (14 days) for the whole farm would need | **≈1,540 gal** | **≈2,560 gal** | |

**Bottom line:** 73 gallons waters this farm for **less than one day**. The farmer alone could stretch it for weeks, but only if the animals get none of it.
