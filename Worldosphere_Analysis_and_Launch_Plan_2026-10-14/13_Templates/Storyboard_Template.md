# Storyboard template (copy as `WS-0NN_board_v01.md`; one block per shot)

Pair it with `Shot_List_Template.csv` (same shot IDs). Draw thumbnails on a 9:16 frame with the safe-zone overlay (`09_Typography_and_Captions/safe_zone_overlay_1080x1920.png`) under the sketch.

## Location floor plan (one per location; reuse it across episodes)
- Top-down sketch: walls, doors (mark PUSH/PULL sides), exits, windows, the threat's entry point, light sources.
- Screen direction rule for this episode (e.g. "home = screen-right").

## Shot block
```
Shot: S__   Time: __.__–__.__ s (dur __.__)   Location: K__ / ____
Thumbnail: [9:16 sketch, with the subject box drawn and the caption lane marked A or B]
Camera: (lens feel, height, angle, move ≤2%/s, or locked)
Action / performance: (key poses: anticipation → action → follow-through → settle; reaction 4–6 frames after the stimulus)
Line(s): (speaker: text)
Text events: (H1 / L1 / T1 / F1 / V1 with in–out times)
Caption lane: A (y 1100–1300) or B (y 470–610); never B during the Fork
Subject box clear of captions? yes / no → fix the staging, not the caption
Sound: (ambience / SFX on sync frame / music state / drop)
Transition out: hard cut / Fork / Sphere expand / Verdict slide / match wipe (max 1)
Continuity: (props in hand, door states, light, weather, injuries, threat position)
```

## Board approval checklist
- [ ] A muted viewing of the animatic is understood by someone new (QA S-01)
- [ ] Geography matches the floor plan in every shot (QA F-08)
- [ ] Captions never cover faces or the decisive action (QA W-05)
- [ ] The Fork, Sphere and Verdict are placed per the recipe; ≤2 Spheres at once
