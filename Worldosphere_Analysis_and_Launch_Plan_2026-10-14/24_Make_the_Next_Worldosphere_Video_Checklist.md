# 24 — Make the next Worldosphere video (one-page checklist)

Work top to bottom. Each line points to the document that holds the detail. Copy this list into the episode folder and tick it there.

**Before writing (T-14 → T-10)**
- [ ] Open the brief `18_Daily_Briefs/WS-0NN_*.md` and the calendar row (17). Check the change log for any swap (21 §8).
- [ ] Note the recipe in brief field 6 (`13_Templates/Production_Recipes.md`) and its word budget.
- [ ] Find every real-world claim in brief field 8 in `07_Survival_Logic_and_Facts/claim_ledger.csv`. **Any UNVERIFIED — BLOCKING claim must be verified by T-10 (procedure: `07_Survival_Logic_and_Facts/Verification_Worksheet.md`), or you swap to the reserve in field 29.**
- [ ] For outbreak episodes, list the world rules used (07 §3: WR-01…WR-12) and run the four consistency checks.

**Write (T-8)**
- [ ] Rules box: geography, exits, threat entry side, screen direction, the fair clue (12 §5.3).
- [ ] Hook: frame 0 has the protagonist + the anomaly; H1 ≤6 words; the first word ≤0.3 s; three options tested muted (brief fields 9–14; playbook 14).
- [ ] Script in `13_Templates/Script_Template.md`:
  - every line reveals, changes, raises or resolves, or deepens
  - character lines ≤7 words
  - the Fork at the recipe position
  - Verdict factor ≤8 words; REAL RULE ≤14 words, in ledger wording.
- [ ] Timed read: run the engine or a stopwatch; within ±3 s of target; caption groups pass the reading-time rule (12 §5.6).

**Plan the pictures (T-7 → T-6)**
- [ ] Storyboard + shot list (`13_Templates/Storyboard_Template.md`, `Shot_List_Template.csv`): camera, action, caption lane, continuity column, subject boxes clear of captions.
- [ ] Animatic on the scratch read; a muted viewer understands it.
- [ ] VO recorded (48 kHz/24-bit, 3 takes; batch with other episodes).
- [ ] Assets: pull rigs and kits from the library; build only the new props; register any third-party asset (`22_Asset_Rights_and_Sources/asset_register.csv`).

**Make it (T-6 → T-3)**
- [ ] Animate critical shots first: hook, Fork (crack 4 frames, hold 1.0–1.6 s, wipe 8 frames), payoff, Verdict. Feet locked, props parented, reactions 4–6 frames late (08 §4.3, §12).
- [ ] The Sphere only where a force decides something; ≤2 domes; plausible distances (08 §8.2).
- [ ] Edit to the VO; one planned drop; the final image holds ≥1.5 s; the Verdict ≥2.5 s.
- [ ] Mix: ambience → SFX → bed → drop → Fork/Verdict cues → motif. −14 LUFS ±1, ≤ −1 dBTP; export stems.
- [ ] Captions re-timed to the final VO; N1 lane A (lane B only when faces are low, never during the Fork); emphasis budget; speaker chips; SRT + ASS (09).

**Check it (T-3)**
- [ ] Run `13_Templates/QA_Checklist.md` sections S, F, V, W and A, plus the episode checklist.
- [ ] **Playback on the actual export file:** a full viewing with sound, a full muted viewing, a phone-size check, critical transitions frame by frame, and continuity points. Record the viewer, device and file version.
- [ ] Export: 1080×1920, 24 fps, H.264 High, AAC-LC 48 kHz, faststart. Paste the ffprobe and ebur128 output into the QA log (12 §2).

**Package it (T-3, banked)**
- [ ] `13_Templates/Upload_Package_Template.md`: title (≤100 characters, true to the video), description ("Fiction scenario" or sources), ≤3 hashtags, pinned comment, cover frame, SRT, **Not made for kids**, synthetic-content toggle **No** for stylized animation.
- [ ] Hand it to the owner for go/no-go. **Do not publish or schedule without the owner's decision.**

**Learn from it (24 h / 72 h / 7 days)**
- [ ] Fill `13_Templates/Performance_Review_Template.md` and the *Tracking* sheet. Compare at the same age; use engaged views as the denominator (21 §1).
- [ ] Diagnose with 21 §6. Change one variable at a time. Log changes in the change log. Never panic-delete or repost.
